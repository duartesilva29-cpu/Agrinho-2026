    1

    Estruture as duas faces

    Uma caixa .cartao guarda a frente e o verso. Um clique alterna a classe virada.

    <div class="cartao" onclick="this.classList.toggle('virada')">
  <div class="lado frente">Pergunta 🌱</div>
  <div class="lado verso">Resposta 🌻</div>
</div>
    2

    Dê profundidade à cena

    O perspective no palco cria o efeito 3D; o preserve-3d deixa as duas faces girarem juntas.

    .cenario { perspective: 900px; }

.cartao {
  position: relative;
  width: 280px; height: 180px;
  transform-style: preserve-3d;
  transition: transform .6s;
}
    3

    Empilhe as faces e esconda o verso

    As duas faces ficam uma sobre a outra. O backface-visibility impede que o texto apareça espelhado.

    .lado {
  position: absolute; inset: 0;
  backface-visibility: hidden;
  border-radius: 14px;
}
.verso { transform: rotateY(180deg); }
    4

    Gire a carta!

    Basta uma classe nova para o cartão dar a cambalhota. Sem JavaScript? O :hover também resolve.

    .cartao.virada { transform: rotateY(180deg); }

/* versão só com CSS: */
.cartao:hover { transform: rotateY(180deg); }
    5

    Capriche no acabamento

    Sombra dura estilo papel, leve subida no hover e respeito a quem prefere menos movimento. ✨

    .frente {
  background: #fffdf4;
  box-shadow: 6px 6px 0 #1d3325;
}

/* acessibilidade em primeiro lugar */
@media (prefers-reduced-motion: reduce) {
  .cartao { transition: none; }
}

    O projeto

    O campo encontraa sala de aula.

    O Programa Agrinho aproxima, há décadas, os saberes do campo da escola paranaense. Na edição 2026, nossa turma aceitou o desafio de transformar conteúdo de estudo em algo vivo: um baralho de flashcards construído inteiramente com HTML e CSS.

    A ideia é dupla: revisar as matérias com estudo ativo — pergunta, resposta, virar a carta — e, ao mesmo tempo, aprender programação de verdade, criando cada carta na mão, linha por linha.

    As cartas falam de tags e seletores, mas também de rotação de culturas, polinização e cuidado com a água. Porque estudar, no fim das contas, é aprender a cultivar. 🌾

    — Estudante do Programa Agrinho, turma 2026
